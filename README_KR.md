# 한빛경찰서 홈페이지 시안 실행 방법

## 로컬에서 실행하기

1. Node.js가 설치된 컴퓨터에서 이 폴더를 엽니다.
2. 터미널에서 `node server.js`를 실행합니다.
3. 브라우저에서 `http://127.0.0.1:8000`을 엽니다. 기존 `file://` 주소 대신 이 주소를 사용해야 민원 제출과 관리자 로그인이 연결됩니다.
4. 페이지 아래쪽의 **관리자 로그인**을 열어 데모 계정 `admin` / `admin1234`로 로그인합니다.

## 페이지 파일

- `index.html`: 경찰서 메인 페이지와 안전 소식
- `about.html`: 경찰서 소개
- `departments.html`: 부서·담당 업무 안내
- `area.html`: 관할 지역과 경찰관서 안내
- `civil.html`: 민원 안내와 접수 양식

각 페이지는 독립된 HTML 파일이며, 상단 메뉴에서 실제 페이지 링크로 이동합니다. 새 HTML 파일을 추가하면 `server.js`의 `allowedFiles` 목록에도 파일명을 추가해야 로컬 서버가 제공할 수 있습니다.

민원은 이 폴더의 `inquiries.json` 파일에 저장됩니다. 관리자는 민원별 답변을 작성할 수 있으며 답변을 저장하면 해당 민원은 자동으로 `답변 완료` 상태가 됩니다. 관리자 로그인은 8시간 뒤 만료됩니다.

관리자 목록은 민원 종류별로 필터링할 수 있습니다. 답변 완료 건은 접수번호·민원 종류·제목만 보이도록 접혀 있으며, 펼치면 상세 내용과 답변을 볼 수 있습니다. 삭제 버튼은 확인 후 서버 저장 목록에서 해당 접수를 제거합니다.

## 관리자 비밀번호 바꾸기

Windows PowerShell에서 서버를 시작하기 전에 환경 변수를 설정할 수 있습니다.

```powershell
$env:ADMIN_USERNAME = "admin"
$env:ADMIN_PASSWORD = "충분히_긴_새_비밀번호"
node server.js
```

## 실제 운영 전 확인

이 서버는 기능 확인용 로컬 시안입니다. 기본 계정은 개발용이고, 민원 저장 파일은 암호화되지 않습니다. 실제 경찰서 서비스로 공개하기 전에 기관 인증 체계, HTTPS, 접근 권한 관리, 감사 기록, 개인정보 보유·파기 정책, 암호화된 데이터베이스와 백업을 담당 부서가 검토하고 운영 환경에 맞게 교체해야 합니다. 민감한 사건 정보나 개인정보를 이 데모에 입력하지 마세요.
